# 我的世界联机服务器：几个人玩该买多大配置，面板一键开服到朋友进服全流程

朋友在群里丢一句“周末开个服吧”，然后你就开始了：下服务端、装 Java、改 `server.properties`、发现家里没公网 IP、折腾内网穿透、被对面连不上教育一晚上。

问题往往不在你手笨，而在路径选错了。联机服有三条路，成本差别很大，先想清楚走哪条，后面会省很多事。

## 先分清三种联机方式，别一上来就买机器

**用自己电脑当主机。** 不花钱，缺点是你关机服务器就没了，家里宽带还得解决公网可达的问题——要么有公网 IPv4，要么上内网穿透（花生壳、frp、异地组网工具都行，Hamachi 免费版只支持 5 人）。适合“今晚玩两小时”的临时局。

**租一台云服务器，自己装服务端。** 自由度最高，能开多个服、装任意环境、跑插件和整合包。代价是你要面对 Linux 或 Windows 远程、Java 版本、防火墙放端口这些事，第一次做通常要一个下午。

**买面板服，网页点几下开服。** 服务端由平台下载和托管，你在网页里点“启动”，看到 `Done (XXs)!` 就说明成功了，剩下的只是把地址发给朋友。适合不想碰命令行的人，也是本文重点讲的路径。

判断标准很朴素：**每天都玩、长期开**，走固定计费或年付；**一周开一次**，动态计费的机器闲置时基本不烧钱，比月付固定划算。

## 配置不是越大越好，按“版本 + 人数 + 模组”倒推

Minecraft 服务端有个反直觉的地方：**主逻辑基本跑在单线程上，单核主频比核心数更重要。** 一台 8 核低主频的机器，开 1.20+ 的服，可能打不过 4 核高主频。第二个瓶颈是内存——服务端本体就要吃掉 1GB 到 1.5GB，之后每个在线玩家再加 200～400MB，每个模组再加 50～200MB。

版本本身也很吃资源。官方页面给过一个参考：**1.18+ 的消耗大约是 1.16+ 的两倍、1.12.2 的三倍**。所以“我朋友服没人也卡”这种问题，八成是版本高、视距开太大。

按玩法粗分，大致是这样：

| 玩法 | 在线人数 | 建议配置 | 分配给服务端的内存 |
| --- | --- | --- | --- |
| 原版 / Paper 纯净生存 | 2–5 人 | 2 核 4G | 2–3G |
| 纯净 + 少量插件 | 5–15 人 | 4 核 8G | 4–6G |
| 50 个模组以内 | 2–5 人 | 4 核 8G | 4–6G |
| 中大型整合包（100+ 模组） | 4–8 人 | 6 核 12G 起 | 8G 以上 |
| 超重型整合包、高实体生电 | 10 人以上 | 8 核 16G 起 | 12G 以上 |

服务端软件的选择逻辑同样简单：纯玩原版或装插件选 **Paper**（性能比原版好，插件生态成熟），要更多自定义就 **Purpur**；玩模组按整合包要求选 **Forge**（大型整合包的标准）或 **Fabric**（更轻、启动快）；人数多的高版本服可以考虑 **Folia**，它是 Paper 的多线程分支。

## 从下单到朋友进服，实际要点的就那么几步

1. **注册并绑定微信**，先去把首月 5 折券领到手。
2. 控制台进 **游戏云 → 购买游戏云**，选服务器类型（雨云面板 / MCSM 面板 / VPS），游戏类型选 Minecraft Java 版或基岩版。
3. 选服务端：纯净、Paper、Purpur、Forge、Fabric、Folia 等按需求挑；开整合包服选“Java 纯环境”，自己传包。
4. 选机型、配置、计费模式（常玩选固定计费，偶尔玩选动态计费）和购买时长，下单。购买时会让你选**在线模式**（开正版验证）还是**离线模式**，之后也能在文件管理里改。
5. 进控制台 → 游戏云 → 管理，打开面板点“启动”，终端出现 `Done` 就是开好了。
6. 回到管理页找 **NAT 端口映射 / 连接信息**，那里写着地址和端口。游戏里点“多人游戏 → 添加服务器”，填 `IP` 或者 `IP:端口`（端口不是 25565 就一定要带上）。
7. 传模组、换存档用面板的**文件管理**，或者用 FileZilla 走 SFTP；面板也支持备份和定时备份，开服前先把备份打开。

## 最容易卡住的几个坑

**版本和 Java 必须对应，装错直接启动失败。** 1.16 及以下要 Java 8，1.17～1.20.4 要 Java 17，1.20.5 及以上要 Java 21。用面板自带的 Java 纯环境可以让平台自己匹配，手动装就要对着版本选。

**Java 版和基岩版不是一回事。** Java 版默认端口 25565（TCP），基岩版是 19132（UDP）。手机玩家想连 Java 服，得额外上 Geyser + Floodgate 做跨版本，配置项不少，建议先读官方文档再动手。

**正版验证是个常见误会。** `online-mode=true` 时，没有正版账号的玩家进不来。想拉没买游戏的朋友，就得改成 `false`，代价是服务端对玩家身份的判定会松散一些。

**视距比配置更容易救急。** 卡的时候先把服务端视距从 10 降到 6，效果往往比升级配置更立竿见影。TPS 持续下降通常就是单核吃满的信号，这时候才需要考虑换机型。

**大陆节点的独立公网 IP 是额外成本，但开服不一定需要。** NAT 模式下平台提供端口映射，共享高防，用来开游戏服足够了；独立 IP 更适合要建站或跑常见 HTTP 端口的场景。

**公开联机要注意合规。** 游戏端口本身一般不涉及域名备案，但如果商业化运营、做内容管理，这些不是靠一个服务器套餐能解决的问题。
